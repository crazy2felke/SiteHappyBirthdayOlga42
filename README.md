# VIP-билет · Ольга · 84

Персональный сайт-приглашение к 84-летию Ольги: выставка одной алмазной картины.

Семья собрала полотно страза за стразой и оставила имениннице последний сегмент — 25 ячеек. 8 сентября — день рождения, 19 сентября — вручение.

## Страницы

1. `index.html` — VIP-билет и история подарка
2. `assemble.html` — сборка последнего сегмента по схеме (цвета 6 / 16 / 25)
3. `gallery.html` — зал с эскизом картины (открывается после сборки)

Исходные фото схемы и портрета лежат в `assets/`. Те же файлы для сайта — в `img/`.

## Как открыть

Статический сайт, сервер не обязателен. Достаточно открыть `index.html` в браузере или поднять любой локальный http-сервер из корня репозитория.
