# Полный саммари проекта

Статичный трёхстраничный сайт-интерактив к дню рождения **Ольги**. Ссылка должна прийти из **VIP-билета на персональную выставку** одной алмазной картины. Картину собрала вся семья; последний сегмент оставлен имениннице. Пока сегмент не собран, готовая часть полотна физически заклеена. Цифровой ритуал: она собирает последний фрагмент на схеме, затем видит **аватар картины** (эскиз-портрет) и предвкушает, как полотно засияет целиком.

Исходный запрос на русском. Стек: чистый HTML + CSS + JS. Без сборки, без npm, без бэкенда.

## Факты про именинницу (верно)

| | |
|---|---|
| Имя | **Ольга** |
| Год рождения | **1984** — это факт для контекста, **не** возраст и **не** то, что пишем на сайте как юбилей |
| День рождения | **8 сентября** |
| Вручение подарка | **19 сентября** |
| Возраст на этот день рождения | **42** (2026 − 1984) |

На сайте везде указывается **возраст 42**, не год рождения. Фраза «84 года» в ранних файлах появилась из года рождения 1984 и была ошибкой. Исправлено: юбилей, заголовки и поздравления — **42 года / 42-летие**.

## Дерево файлов

Сайт лежит в **корне репозитория** (не в подпапке `site/`):

```
index.html          страница 1 — VIP-приглашение
assemble.html       страница 2 — сборка сегмента
gallery.html        страница 3 — аватар картины
css/styles.css      общие стили + шары, торт, кнопка музыки
js/assemble.js      сетка, клики, localStorage, гейт 25/25, завеса
js/gallery.js       гейт зала (нужен флаг завершения)
js/atmosphere.js    музыка, конфетти, шарики, кнопка ♪
img/favicon.svg     иконка-ромб
img/portrait.jpg    портрет Ольги — обязателен для gallery.html
img/schema.jpg      исходная схема сегмента (референс; сетка собрана в JS)
assets/             те же исходные фото схемы и портрета
SUMMARY.md          это саммари
README.md           краткое описание
```

Референс схемы в HTML не показывается: сетка собрана в JS/CSS. `img/schema.jpg` есть как исходник.

Портрет на диске есть (`img/portrait.jpg`, женщина, тёмные волосы, красная помада). Без него третья страница с пустой рамой.

## Навигация

```
index.html  --«Начать сборку»-->  assemble.html  --«Завершить сборку»-->  gallery.html
     ^                                                                      |
     +-----------------------------«Вернуться»------------------------------+
```

Три отдельных HTML, не SPA. С билета только «Начать сборку» — ссылки в зал на первой странице нет.

«Завершить сборку» не пускает на страницу 3, пока не собраны все **25** рабочих ячеек. Прямой заход на `gallery.html` без флага **текущей сессии** показывает экран «Ещё закрыто». После сборки — завеса «Плёнка сходит…», затем зал. Старый флаг в `localStorage` сбрасывается, чтобы повторное открытие сайта не пропускало в зал.

## Сценарий в текстах (как задумано)

**Страница 1.** Адрес пришёл с VIP-билетом; гость одна — Ольга. Семья разделила праздник: 8 сентября — день рождения, 19 сентября — вручение картины. Последний сегмент её; пока не соберёт — полотно под заклейкой. Сначала путь сборки на фрагменте, потом аватар и предвкушение света целиком. На билете: **42 года**, не 1984 и не 84.

**Страница 2.** Клик кладёт/снимает стразу. Двойное нажатие на ячейку снимает предыдущие стразы в этой строке (слева от текущей). Крестики не часть фрагмента.

**Страница 3.** Это эскиз, не живая картина. Живую она увидит в алмазах 19 сентября, когда снимет заклейку и поставит последнюю стразу. Подпись семьи.

Название выставки: **«Последний сегмент»**. Билет № 01, дата вручения на билете — 19 сентября.

## Страница 2 — схема

Сетка **10×10**. Подписи 1–10 со всех сторон. `null` = крестик, клик запрещён.

```
Строка 1: 6¹  6²  6³  16¹  25¹  × × × × ×
Строка 2: 6¹  16¹ 6¹  6²   16¹  × × × × ×
Строка 3: 6¹  6²  6³  6⁴   16¹  × × × × ×
Строка 4: 6¹  6²  6³  6⁴   16¹  × × × × ×
Строка 5: 6¹  6²  6³  6⁴   6⁵   × × × × ×
Строки 6–10: все ×
```

**25 рабочих** + **75 заблокированных**. Цвета: `6` чёрный `#141414`, `16` бордо `#4a1014`, `25` алый `#c51e32`.

Счётчик `N / 25`. Кнопка визуально `is-disabled`, пока не 25 (класс, не HTML `disabled`). На 25/25 кнопка золотая (`is-ready`).

## Хранение

| Ключ | Где | Значение |
|---|---|---|
| `diamond-last-segment` | localStorage | JSON-массив id клеток `"строка-столбец"` 0-based (`"0-0"` = клетка 1,1) |
| `diamond-segment-complete` | **sessionStorage** | `"1"` после «Завершить сборку» в этой вкладке; читает только `gallery.js` |
| `diamond-music-muted` | localStorage | `"1"` если музыку выключили |
| `diamond-music-wanted` | localStorage | хочет ли гость музыку |

Прогресс страз переживает перезагрузку. Флаг зала живёт только в сессии вкладки: новое открытие сайта не пускает сразу на последнюю страницу. Старый ключ `diamond-segment-complete` в localStorage удаляется при заходе.

## Атмосфера

- Музыка: свой луп на Web Audio (не чужой трек, без сети). Браузер не стартует звук без касания — кнопка слева внизу **«Включить музыку»**. На всех трёх страницах.
- Конфетти (золото / крем / алый), шарики по краям, CSS-торт со свечой на билете и в зале.
- На схеме шаров меньше, чтобы сетка кликалась.
- В зале при открытии — вспышка конфетти.
- `prefers-reduced-motion` отключает анимации.

Шрифты Google: **Cormorant Garamond** + **Manrope**. Без сети откат на Times / Segoe UI.

Палитра: фон `#0c0a08`, золото `#c6a36a` / `#e8c98a`, крем `#f7f1e6`.

## Как открыть локально

Из корня репозитория:

```bash
python3 -m http.server 3456
```

Открыть http://127.0.0.1:3456/

Не открывать `index.html` двойным кликом, если нужен предсказуемый localStorage и шрифты.

## Как выложить в интернет (ссылка в VIP-билет)

Нужна публичная статика, корень = содержимое репозитория (`index.html` в корне домена).

- **Netlify Drop** — перетащить папку, ссылка за минуту. Без аккаунта может протухнуть; с бесплатным аккаунтом доживёт до 19 сентября.
- GitHub Pages / Cloudflare Pages / Vercel.

HTTPS желателен (localStorage, шрифты, телефон). Хостинг ещё **не сделан**.

## Ограничения

1. Это ритуал перед живой картиной, не физическая алмазка.
2. Страница 3 — эскиз-селфи, не собранная мозаика.
3. Схема воссоздана в HTML, не наложена на JPG.
4. Защита зала — только `sessionStorage`, не сервер. Новое открытие сайта зал не открывает.
5. Музыка начинается после жеста (политика браузера).
6. Публичного URL ещё нет.
7. На сайте указывается **возраст 42**, не год рождения и не «84».
